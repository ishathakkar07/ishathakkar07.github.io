# Thrift IC

A four-page fictional Iowa City thrifting guide for MKTG:4400 at the University of Iowa. All copy, layout, shop examples, and SVG illustrations were created with ChatGPT.

## Upload and publish

1. Unzip the download.
2. Open https://github.com/ishathakkar07/ishathakkar07.github.io.
3. Choose Add file > Upload files.
4. Open the unzipped folder and drag all the files inside it into GitHub. Do not upload the ZIP or put an extra folder around the files. index.html must be at the top level beside README.md.
5. Use a commit message such as: Add four thrift guide pages so visitors can browse shops, outfits, and tips. Commit directly to main.
6. Open Settings > Pages. Select Deploy from a branch, main, and / (root), then Save.
7. Allow up to about 10 minutes for publication, then open https://ishathakkar07.github.io/ in a private browser window.

## Pages

- index.html: Home
- thrift-shops.html: Fictional shop directory with working category filters
- vintage-clothing.html: Two illustrated outfit ideas
- thrifting-tips.html: Beginner tips and an interactive checklist

styles.css controls the appearance. site.js controls filters and checklist interactions. The three SVG files are local illustrations. No installation or build command is needed for GitHub Pages.
